- 필터링된 새 출력(28건)으로 실전송 시도 → `HTTP 400: message is too long` 발생. Python `len()`으로는 4096자 미만이었는데도 거부됨.
- 원인 2가지 확인: (1) 텔레그램 4096자 한도가 UTF-16 코드유닛 기준인데, 이번에 추가한 이모지가 대부분 서로게이트 페어 문자라 `len()`(코드포인트 수)보다 실제 길이가 더 큼. (2) `chunk_blocks()`가 본문만 4096자로 재고 실제 전송 시 붙는 제목+빈줄은 계산에 안 들어가 있었음.
- 수정: `tg_len()`(UTF-16 코드유닛 계산) 추가, 청크 분할을 `len()`→`tg_len()` 전환 + 제목 오버헤드 여유분(200자) 선반영. 재검증: 4/4건 전송 성공, 사용자 실제 수신 확인("도착했고 보기 좋다"), peak RSS 28MB/20초.
